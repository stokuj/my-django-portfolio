Granular Data Clustering in Python

Detecting one dominant cluster while separating noise

This research project compares clustering strategies for a specific objective: identify a single coherent cluster and classify the remaining points as noise. It combines classical algorithms with custom granular quality metrics.

Key Contributions

  • Comparison of DBSCAN, Single Linkage, and Complete Linkage.
  • Evaluation on multiple synthetic shapes with varied noise levels.
  • Custom P1-P3 and neighbor-based quality criteria for model selection.
  • Automated parameter sweeps and CSV-based experiment outputs.

Tech Stack

Python 3.9+ NumPy scikit-learn SciPy Pandas Matplotlib
