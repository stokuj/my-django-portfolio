Weather Web Scraping

Desktop weather monitoring with IMGW data, PostgreSQL storage, and Plotly charts

This desktop project collects current observations from IMGW, persists records in PostgreSQL, and visualizes weather trends across multiple time windows.

Features

  • Automated fetch from IMGW Synop endpoint.
  • Storage and filtering in PostgreSQL.
  • Interactive charts for temperature, precipitation, wind, humidity, and pressure.
  • CSV export for filtered datasets.

Tech Stack

Python 3.10+ Tkinter Plotly requests BeautifulSoup PostgreSQL

Project Layout

weather-web-scraping/
|-- app.py
|-- functions.py
|-- data.csv
|-- downloaded.csv
`-- .env.example
Setup and Run
Copy-Item .env.example .env
uv sync
uv run python app.py
