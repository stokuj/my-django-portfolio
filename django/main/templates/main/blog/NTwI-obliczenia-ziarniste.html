The application implements core fuzzy-number operations where each value is represented by three parameters: left bound, center, and right bound.

Supported Operations

  • Display a single fuzzy number.
  • Multiply by a scalar and exponentiation.
  • Add, subtract, and multiply two fuzzy numbers.
  • Evaluate chained operations across multiple inputs.
