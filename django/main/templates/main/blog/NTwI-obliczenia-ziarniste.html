{{ project.title }}

A fuzzy-granule distance project from the New Technologies in Computer Science course, focused on arithmetic over triangular fuzzy numbers.

Fuzzy Logic

The program implements arithmetic operations on fuzzy numbers represented by triangular membership functions.

Each fuzzy number is defined by three parameters: x1 (left point), m (center with membership degree 1), and x2 (right point).

A fuzzy set assigns each element a membership degree in the range [0, 1].

This project uses triangular membership functions parameterized by x1, m, and x2.

Supported Operations

  • Display a single fuzzy number
  • Multiply by a real scalar
  • Raise a fuzzy number to a power
  • Add two fuzzy numbers
  • Subtract two fuzzy numbers
  • Multiply two fuzzy numbers
  • Evaluate chained expressions

CLI Usage

Install dependencies:

uv sync

Display a single fuzzy number:

uv run python app.py x1 m x2
uv run python app.py 2 3 4

Scalar multiplication or exponentiation:

uv run python app.py x1 m x2 operator value
uv run python app.py 2 3 4 * 2
uv run python app.py 2 3 4 ^ 2

Operations on two fuzzy numbers:

uv run python app.py x1_A m_A x2_A operator x1_B m_B x2_B
uv run python app.py 2 3 4 + 5 6 7
uv run python app.py 2 3 4 - 1 2 3
uv run python app.py 2 3 4 * 1 2 3

Chained operations:

uv run python app.py x1_A m_A x2_A operator1 x1_B m_B x2_B operator2 x1_C m_C x2_C ...
uv run python app.py 2 3 4 + 5 6 7 - 1 2 3

Implementation Notes

The tool is implemented as a lightweight Python CLI application (Python 3.10+) with uv used for dependency and environment management.

The codebase is intentionally small and focused: app.py handles command-line input and operation flow, while RozmytyZbior.py contains fuzzy-number modeling and arithmetic logic.
