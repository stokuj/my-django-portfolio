cartoon-filter is an engineering project focused on building a cartoon-style image filter and comparing performance between C++ and x64 Assembly implementations inside one Windows solution.

The main objective was educational and experimental: implement the same processing approach in C++ and ASM, integrate both into a C# desktop app, and use the project to study cross-language architecture, native interop, and optimization tradeoffs.

The objective was achieved: both native paths were implemented and integrated, the application runs in x64 builds, and the full workflow (load image, tune density, apply filter, save output) works in a single executable environment.

Software Engineering Outcomes

  • Working cross-language architecture: C# -> C++/ASM DLL with runtime integration.
  • Functional image-processing pipeline for BMP, JPG, and PNG formats.
  • Practical setup for C++ vs ASM speed comparison and low-level optimization learning.

Build and Validation

Build and validation are centered on Visual Studio 2022 and the x64 target. Build GraphicFilter.sln (Debug or Release), then run artifacts from bin\x64\<Configuration>\. 

msbuild .\GraphicFilter.sln /t:Build /p:Configuration=Debug /p:Platform=x64

Requirements

  • Windows (x64)
  • Visual Studio 2022 with C#/.NET desktop and C++ workloads
  • MASM build tools
  • .NET Framework 4.8 runtime
How to Run
msbuild .\GraphicFilter.sln /t:Build /p:Configuration=Debug /p:Platform=x64
# then run the desktop app from:
.\src\GraphicFilterPrototyp\bin\x64\Debug\GraphicFilterPrototyp.exe
