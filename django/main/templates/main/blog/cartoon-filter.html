Cartoon Filter is an engineering project comparing performance between C++ and x64 ASM implementations integrated into one desktop app.

Key Features

  • C# to C++/ASM DLL integration
  • Image filtering for BMP/JPG/PNG
  • x64-focused native build setup
  • Performance comparison baseline

Tech Stack

C#C++x64 ASMWinFormsVisual Studio 2022

Project Structure

cartoon-filter/
|- GraphicFilter.sln
`- src/
   |- GraphicFilterPrototyp/
   |- CppCode/
   `- ASMCode/
How to Run
msbuild .\GraphicFilter.sln /t:Build /p:Configuration=Debug /p:Platform=x64
# then run:
.\src\GraphicFilterPrototyp\bin\x64\Debug\GraphicFilterPrototyp.exe
