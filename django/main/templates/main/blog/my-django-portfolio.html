Django Portfolio Blog

Portfolio and blog platform built with Django, PostgreSQL, Tailwind, and Docker

This repository is the core portfolio project: a production-oriented Django app with project detail pages, filtering, tagging, and deployment-ready infrastructure with Gunicorn and Caddy.

Highlights

  • Project list and details with status and tag system.
  • PostgreSQL-backed data model and visitor counter.
  • Tailwind + DaisyUI frontend and responsive templates.
  • Docker Compose setup with Caddy reverse proxy.

Tech Stack

Python 3.13 Django 5 PostgreSQL Tailwind DaisyUI Docker

Docker Quick Start
cp .env.example .env
docker-compose up --build -d
Local Quick Start
uv sync
npm install
npm run build:css
python django/manage.py migrate
python django/manage.py runserver
Tailwind build path: django/main/static/src/css/input.css -> django/main/static/css/style.css.
