Activity Tracker

Django app for activity logging, social feed, and progress analytics

Activity Tracker is a Django 5 project focused on daily physical activity management. It combines structured tracking, social interactions, and visual reporting in one workflow.

Highlights

  • User auth with Google OAuth support via django-allauth.
  • Activity tracking by category and duration.
  • Post/comment feed with follow and profile privacy controls.
  • CSV import/export and Plotly-based activity reporting.

Tech Stack

Python 3.10 Django 5 PostgreSQL Plotly Pandas uv

Project Layout

activity_tracker/
|-- manage.py
|-- activityTracker/
|-- templates/
|-- static/
`-- pyproject.toml
Quick Start
uv sync
uv run python manage.py migrate
uv run python manage.py runserver
Local startup validates PostgreSQL connectivity and fails fast on invalid DB config.
