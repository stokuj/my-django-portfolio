Activity Tracker is a Django web application for tracking physical activity, sharing posts, and generating activity statistics.

Tech Stack

Python 3.10Django 5PostgreSQL

Libraries/Tools

uvPlotlyPandasCrispy Forms

Key Features

  • User registration and authentication with Google OAuth
  • Activity tracking by category and duration
  • Social feed with posts, comments, and follow/unfollow
  • CSV import/export for activities and Plotly reports
  • Profile privacy and account settings
