How to Run

Requirements: Python >=3.10,<3.13 and uv.

Install dependencies and start the desktop app:

uv sync
uv run python app.py

Typical workflow in the app: select currency/source/model, configure prediction horizon and plot range, click Train, then use Plot and GAIN.

Showcase

GUI

The desktop interface is organized into four key areas: currency selection, online source selection, model architecture selection (LSTM/GRU/LSTM+GRU), and a settings panel for prediction lookback, future horizon, and plot range. Actions include training, plotting, gain calculation, and loading local CSV data.

Prediction Chart

After training, the Plot action opens a Matplotlib chart with actual vs predicted prices. Predicted values are shifted by Future days, so each point aligns with its target date on the X-axis.
