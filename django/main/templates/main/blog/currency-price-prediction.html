Crypto Currency Price Prediction

Desktop forecasting app with LSTM, GRU, and hybrid recurrent models

This project provides a Tkinter GUI for training and evaluating neural models for crypto price prediction. It supports online and offline data sources with interactive visualization of forecast vs actual values.

Highlights

  • Markets: BTC, ETH, DOGE, LTC.
  • Model options: LSTM, GRU, and LSTM+GRU.
  • Training in background thread with progress and ETA.
  • Date-aware charts and simple gain calculation.

Tech Stack

Python 3.10+ TensorFlow Keras Pandas scikit-learn Tkinter
