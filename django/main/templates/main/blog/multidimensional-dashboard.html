{{ project.title }}

The application enables exploratory analysis of high-dimensional data through parallel coordinates and parallel categories charts. It runs as a local desktop app while serving Dash in the background.

Highlights

  • Supports CSV, XLS/XLSX, TSV, and TXT input files.
  • Interactive table with filtering, sorting, and pagination.
  • Parallel Coordinates and Parallel Categories visual layers.
  • Eel desktop host with graceful local port fallback.

Tech Stack

Python 3.11+ Dash Plotly Pandas Eel uv
