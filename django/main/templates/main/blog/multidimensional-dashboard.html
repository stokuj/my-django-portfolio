Key Features

  • Upload and parse CSV, XLS/XLSX, TSV, and TXT files
  • Interactive Dash table (filter, sort, paginate)
  • Parallel Coordinates and Parallel Categories visualizations
  • Desktop app flow with Eel + local Dash server
How to Run

Requirements: Python 3.11+ and uv.

uv sync
uv run python main.py

Runtime behavior:

  • Dash server starts at http://127.0.0.1:8050.
  • Eel opens a desktop host (default localhost:8000, with fallback when port is busy).
  • Closing the desktop window shuts down the Dash server.
Showcase

GUI

The application runs as a desktop window (Eel) with an embedded Dash interface. Main sections include a tab bar (Program/Settings), file drop zone, chart area, and a COLOR_ID legend.

Visualization Modes

Parallel Coordinates: each record is drawn as a polyline across numeric axes, with color mapped to COLOR_ID for quick cluster/outlier detection.

Parallel Categories: records are grouped into ribbon bands between binned axes; ribbon width shows group size and colors follow COLOR_ID.
