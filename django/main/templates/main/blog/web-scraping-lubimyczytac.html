Lubimyczytac Scraper to Goodreads Pipeline

Selenium pipeline for scraping, enrichment, and Goodreads-ready export

This project reads a public Lubimyczytac profile library, enriches each book with additional metadata, and converts the final dataset to a CSV format compatible with Goodreads import.

Pipeline Phases

  • Phase 1: profile pagination scrape to dane/books.csv.
  • Phase 2: per-book enrichment (ISBN and original title) to dane/books_enriched.csv.
  • Phase 3: Goodreads schema mapping to dane/goodreads.csv.

Tech Stack

Python 3 Selenium ChromeDriver CSV processing uv
